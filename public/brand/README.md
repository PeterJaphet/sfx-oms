# Supplied SFx Burger logo artwork

Source: user's `SFx Burger Logo (SVG Transperent Background).zip`.
Primary / black / white are files 10.svg / 11.svg / 12.svg respectively.
The original exported SVGs are preserved byte for byte in `source/`.

The display wordmarks adjust only the root viewport to fit the original artwork with clear space.
`burger-mark.svg` contains the original eight burger elements and their original clip definitions.
No path coordinates, fills, lettering, proportions or effects are changed.
The report PNG and home-screen PNGs are raster exports of those same vectors. The maskable icon
keeps the complete symbol inside the central safe circle on an opaque soft-cream background.
